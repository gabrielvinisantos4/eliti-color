ELITI COLOR — Catálogo interativo
=================================

Estrutura
  index.html        estrutura da página (hero, catálogo, seleção, obras, contato)
  css/estilo.css    visual e animações
  js/dados.js       >>> ÚNICO ARQUIVO PARA CADASTRAR CONTEÚDO <<<
  js/app.js         lógica (catálogo, seleção, WhatsApp, galeria, vídeo no scroll) — não precisa editar
  assets/lata/      quadros do vídeo da lata (d = computador, m = celular) + poster.webp
  assets/produtos/  fotos reais das latas (Mercure: catálogo 2025)
  assets/           logo, vídeo de fundo e imagens

Onde cadastrar (tudo em js/dados.js)
  Catálogos -> lista "catalogos": cada catálogo vira uma aba (hoje: Coral e Mercure)
               { id, marca, titulo, linha, itens: [...] }
  Cores/produtos -> dentro de "itens" de cada catálogo:
               { id, nome, codigo, hex, linhas, imagem, imagemAlt }
               codigo/linhas/imagem são opcionais: o que não existir não aparece
  Latas     -> arquivos em assets/produtos/ (PNG/WebP com fundo transparente),
               ligados pelo campo "imagem" de cada item
  Obras     -> lista "obras":     { titulo, local, tipo, imagem, video }
               (coloque os arquivos em assets/obras/; enquanto a lista estiver
               vazia, a galeria mostra espaços reservados neutros)
  Atendentes-> lista "atendentes": { id, nome, whatsapp (55+DDD+número), telefone }
  Mensagem do WhatsApp -> bloco "mensagem"
